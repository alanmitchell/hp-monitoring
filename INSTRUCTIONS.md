I would like to add code to create a "frost" derived sensor. The sensor indicates the estimated amount of frosting on the evaporator coil, using a floating-point scale of 0 to 10.  When the evaporator fan is running, as indicated by a coil_pressure in excess of 20 Pa, this derived frost score can be derived from the coil_pressure sensor.  A coil_pressure of 23 Pa or less is a frost score of 0.0. A coil_pressure of 80 Pa or more is a frost score of 10.0. The frost score should change linearly between those two pressure values.  When the evaporator fan is running, the frost score should store every 15 seconds and should use the average coil_pressure from a 15 second interval centered on the frost score timestamp.

When the evaporator fan is not running (coil_pressure less than 20 Pa), the frost score should be derived from coil images. Every time a coil image is stored, a frost score should also be stored with the same timestamp. The image processing function that generates the frost score needs to be developed by you. The training data for this development is available in the neighboring `hp-data` directory (../hp-data). `heatpump.duckdb` in that directory is not live but holds real data from the mini-pc.  Images are also contained in ../hp-data. For training, use images and coil_pressure data starting with November 16, 2026 1:42 PM -09 (Alaska Standard Time).  To develop the frost-from-image function find all images that occur when the coil_pressure is in excess of 20 Pa and calculate the coil-pressure based frost score for those images. That should provide a set of training images and frost scores to develop a function from.

After development of an image-to-frost function and a coil_pressure-to-frost function, provide a way to produce frost scores for historical data occurring after the Nov 16 1:42 PM start time.  Also, modify the code to produce the frost score on an ongoing basis.

Note that I do not want to use the `image_metrics` table. I want the frost values to appear as a sensor so they can be included in the hp-web graphs.
